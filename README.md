# sotsuten

●Outline(開催概要)<br>
場所・日時・入場料金といった情報が今年度のものと合っているかどうかを一応確認しましょう。<br>

●Greeting(開催にあたって)<br>
ここには、学類長挨拶を掲載します。<br>
価値創造デザイン学類長の先生に直接メールをして、挨拶の文章を貰いましょう。<br>

●Contents(展示研究室)<br>
ここには、どの研究室から誰が出展するかを掲載します。<br>
「json」フォルダ内にある「exhibitor.json」を編集し、出展者の情報を今年度のバージョンに変更しましょう。<br>

●Event(イベント)<br>
ここには、自主レビューの開催情報(場所・日時・主催)やゲスト講師のプロフィールを掲載します。<br>
自主レビュー班の方と連絡を取り、必要な情報を回してもらいましょう。<br>
回してもらったゲスト講師の情報は、「json」フォルダ内にある「lecture.json」に書きましょう。<br>

●Access(アクセス)<br>
ここには開催場所の地図を載せます。<br>
開催場所が合っているかどうかを一応確認しましょう。<br>

<h1>最後に</h1>
ポスターコンペ優勝者や自主レビュー班、学類長の先生に連絡を取れる体制を整えておくと、Webサイトに載せる内容もスムーズに集められると思います。
