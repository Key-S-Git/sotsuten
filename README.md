#   卒業制作展2025

2025年度のものをもとにWebサイトを開発する方向けに一応残しておきます！<br>
0から開発したい場合は読まないでもらっても大丈夫です！

<h2>各セクションの内容</h2>
<h3>●Outline(開催概要)</h3>
場所・日時・入場料金といった情報が今年度のものと合っているかどうかを一応確認しましょう。<br>

<h3>●Greeting(開催にあたって)</h3>
ここには、学類長挨拶を掲載します。<br>
価値創造デザイン学類長の先生に直接メールをして、挨拶の文章をもらいましょう。<br>
挨拶を考える時間も必要だと思われるので、なるべく早めに依頼を出しておくのが良いと思われます。<br>

<h3>●Contents(展示研究室)</h3>
ここには、どの研究室から誰が出展するかを掲載します。<br>
「json」フォルダ内にある「exhibitor.json」を編集し、出展者の情報を今年度のバージョンに変更しましょう。<br>

<h3>●Event(イベント)</h3>
ここには、自主レビューの開催情報(場所・日時・主催)やゲスト講師のプロフィールを掲載します。<br>
自主レビュー班の方と連絡を取り、必要な情報を回してもらいましょう。<br>
回してもらったゲスト講師の情報は、「json」フォルダ内にある「lecture.json」に書きましょう。<br>

<h3>●Access(アクセス)</h3>
ここには、開催場所の地図を掲載します。<br>
開催場所が合っているかどうかを一応確認しましょう。<br>

<h2>最後に</h2>
Webサイト開発において、デザインのチェックをしていただいたり、外部から必要な情報をいただく機会がたくさんあるかと思われます。<br>
そのため、ポスターコンペ優勝者、自主レビュー班、学類長の先生に連絡を取れる体制を整えておくことが重要になります。<br>
予稿提出や研究発表、展示準備等が重なって大変な時期かと思いますが、計画的に進めていただけたらなと思います！<br><br>
