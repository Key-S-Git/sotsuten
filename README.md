#   卒業制作展2025

2025年度のものをベースに卒展のWebサイトを開発する方向けに一応残しておきます！<br>
0から開発したい場合は読まないでもらっても大丈夫です！

<h2>各セクションの内容</h2>
<h3>●Outline(開催概要)</h3>
場所・日時・入場料金といった情報が今年度のものと合っているかどうかを確認しましょう。<br>

<h3>●Greeting(開催にあたって)</h3>
ここには、学類長挨拶を掲載します。<br>
価値創造デザイン学類長の先生に直接メールをして、挨拶の文章をいただきましょう。<br>
挨拶を考える時間も考慮して、なるべく早めに依頼を出しておくのが良いと思われます。<br>

<h3>●Contents(展示研究室)</h3>
ここには、どの研究室から誰が出展するかを掲載します。<br>
「json」フォルダ内にある「exhibitor.json」を編集し、出展者の情報を今年度のバージョンに変更しましょう。<br>

<h3>●Event(イベント)</h3>
ここには、自主レビューの開催情報(場所・日時・主催)やゲスト講師のプロフィールを掲載します。<br>
自主レビュー班の方と連絡を取り、必要な情報を回していただきましょう。<br>
回してもらったゲスト講師の情報は、「json」フォルダ内にある「lecture.json」に書きましょう。<br>
ゲスト講師の顔写真のデータは、「img」フォルダ→「lectures」フォルダ内に置きましょう。<br><br>
※1月末～2月頭になってもゲスト講師の情報が確定しない場合は、講師プロフィールの部分を削って先に公開するのもOKです。<br>
(Webの公開が遅くなると来場者が減る恐れもあるため)

<h3>●Access(アクセス)</h3>
ここには、開催場所の地図を掲載します。<br>
開催場所が合っているかどうかを確認しましょう。<br>

<h2>制作の流れ</h2>
<ul>
  <li>Figma等でWebのデザインを作成</li>
  <li>デザインをもとに仮実装</li>
  → 学類長挨拶等の必要な情報はこの段階までに集めておくと楽です。<br>
  → 過去のWebのデータは佐藤先生(Web担当の先生)が持っているはずなので、必要であれば連絡して送ってもらいましょう。
  <li>GitHub Page等を利用して仮公開</li>
  <li>仮公開ページをポスターコンペ優勝者にも見てもらい、フィードバックをいただく(※念のため)</li>
  <li>フィードバックをもとに修正</li>
  <li>完成したらWebのフォルダを佐藤先生(Web担当の先生)に渡し、URLの発行を依頼</li>
  → 学類のサーバーにアップロードすることで正式なURLが発行されます。<br>
  → URLの発行からGoogle検索に引っかかるようになるまで2日かかりました。(※2025年度の場合)
  <li>URLが出来たら友渕先生(広報の先生)にメールで共有</li>
  <li>卒展のTeamsにて、完成した旨の報告＆URLの共有</li>
  → サイトのURLはDMやリーフレット等の他媒体にも掲載するので、必ず報告しましょう。
</ul>

<h2>外部から集める情報・素材</h2>
<ul>
  <li>ポスターコンペ優勝者</li>
  <ul>
    <li>ファビコン</li>
    <li>OGP画像(SNS等で共有した時に出てくるサムネイル画像)</li>
    <li>その他メインビジュアル関連の素材(※必要であれば)</li>
  </ul>
  <li>価値創造デザイン学類長</li>
  <ul>
    <li>学類長挨拶</li>
    <li>顔写真</li>
  </ul>
  <li>自主レビュー班(ゲスト担当)</li>
    <ul>
    <li>自主レビューの開催日・時間</li>
    <li>ゲスト講師の情報(名前・所属・経歴・顔写真)</li>
  </ul>
  <li>Web担当の先生</li>
  <ul>
    <li>過去のWebデータ(※必要であれば)</li>
  </ul>
</ul>

<h2>最後に</h2>
Webサイト開発において、ポスターコンペ優勝者にデザインを監修していただいたり、学類長の先生や自主レビュー班の方から必要な情報をいただく等、外部と連絡する機会がたくさんあるかと思われます。<br>
そのため、こうした外部の方と連絡を取れる体制を早めに整えておくことが重要になります。<br>
予稿提出や研究発表、展示準備等が重なって大変な時期かと思いますが、計画的に進めていただけたらなと思います！<br><br>
